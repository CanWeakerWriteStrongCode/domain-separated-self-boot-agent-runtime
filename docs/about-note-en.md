# Project Note

An open-source landing repository for a personally original architecture.

Chinese name: 分域受控自举智能体架构
English name: domain-separated-self-boot-agent-runtime
Codename: BaijiMind (白鳍豚心智)
Alternate name: DolphinMind (海豚心智)
Mascot: the baiji (Yangtze river dolphin) — a tribute to DeepSeek's whale imagery: baiji dolphins live in coordinated groups and sense through echolocation, echoing the architecture's core of "multi-domain autonomy + mutual awareness and coordination". The baiji became functionally extinct due to uncontrolled human production activity; naming the project after it signifies "autonomous systems must be controlled, lest history repeat itself".

## Originality Statement

The entire core logic of this architecture — domain separation, privileged governance, controlled self-boot, and multi-form evolution — was independently thought out and designed by me. It is an original agent-architecture approach. Any directional similarity to existing research is independent convergence, not reference.

Routine work such as day-to-day coding, terminology unification, and document polishing has been assisted by AI; but the architectural innovation, design thinking, and core rules are led and originally produced by me.

## Inspiration

I have referenced mainstream agent frameworks on the market, DeepSeek-Harness, and related R&D thinking. Existing frameworks generally lack security isolation and governance — self-boot is unconstrained, in essence completely free self-boot, difficult to industrialize. This project is an original architecture solution designed against precisely these pain points.

## Current Version Status

Currently at v0.1 validation stage, mainly to land and validate the feasibility of this original architecture and build a solid foundation. It has not yet been polished in large-scale production environments; suitable for learning, reference, and re-development. It is not recommended to put it directly into production as-is — if you use it yourself, harden it as needed.
