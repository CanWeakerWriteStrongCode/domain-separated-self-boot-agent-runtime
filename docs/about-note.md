## 原创说明

整套架构的核心逻辑——分域隔离、特权管控、受控自举、多形态演进——都是我自己独立思考设计的，是一套原创的 Agent 架构思路。若与既有研究存在方向性近似，属独立收敛而非参考。

日常写代码、术语统一、文档润色这些琐碎工作有借助 AI 辅助；但架构创新、设计思路、核心规则，由我本人主导、原创产出。

## 项目灵感来源

参考了市面上主流的 Agent 框架、DeepSeek-Harness 等相关研发思路。现有框架普遍缺少安全隔离与管控、自举无约束，本质是完全自由自举，难以落地工业化。本项目就是针对这些痛点设计的原创架构方案。

## 当前版本状态

目前是 v0.1 验证版，主要用来落地、验证这套原创架构的可行性，打好基础模型。暂时没经过大规模生产环境打磨，适合学习、参考、二次改造，不建议直接裸上线生产，自己用记得按需加固。

后续会持续迭代，补齐知识库、工作流、稳定性、生产适配等能力。AI 将通过 IM、邮件与文档上传持续获取项目上下文，让需求与历史决策自然流入生产流程。长远目标是做成一套好用、安全、可落地的企业级可控自举 Agent 基础框架。欢迎 Star、Fork、交流讨论，一起完善这套新架构！
